# Miracle 迭代闭环与曲线（要求 1 后半 + 要求 5）

> 代码：`src/agentbench_frame/miracle/iterate.py`、`agent_bridge.py`（v1/v2 策略）
> 测试：`tests/miracle/test_iterate.py`

## 1. 迭代闭环管线

```
评测(run_match) → trace/replay 落盘 → 决策点收集(逐 obs) → IG(ig.py)
→ 新版本策略保存(AGENTS 注册) → 导出(AgentBenchResults 契约) → 曲线
```

- **要求 1 后半**：Agent 修改 = 策略版本更新（`SampleAgent` → `SampleV2Agent`，
  召唤优先级反转），新版本在 `AGENTS` 注册即"保存"，再评测由
  `run_iteration(agent_name, seed, iteration)` 完成；对局产物（`.mrc` +
  `.trace.jsonl`）按 iteration 打标落盘，日志可追溯。
- **要求 4 对接**：`collect_decision_points` 在同一 obs 流上用新旧版本决策，
  构造 ε-soft 分布（1-ε 最优 + ε 均匀；确定性 one-hot 会使跨版本支撑集
  不相交而 KL 全部发散，ε-soft 是 RL 常用平滑口径，缺失仍如实记录），
  交 `episode_ig` 计算严格 KL。
- **数据契约（AgentBenchResults）**：`export_run` 写
  `agentbench_data/runs/24_miracle/<策略族>/<iterN_version_seedN>/`：
  - `run.toml`：`type/created/git_commit/agent_version/iteration/seed/winner/rounds`
  - `summary.json`：标准字段（`run_type/created/git_commit/game/agent/win_rate`）
    + 扩展（`score/scores/episode_ig/ig_coverable_ratio/ig_missing/replay/trace`）
  - `ig.json`：逐决策点 IG 明细
  - `aggregate.py` 可直接扫描生成 registry.toml。

## 2. 演示结果（本轮受控最小迭代，如实保留失败）

策略族 `sample`，对手 `EndRoundAgent`，seed=11，各真实评测 1 局：

| iteration | version | score | winner | rounds | episode_ig | coverable |
|---|---|---|---|---|---|---|
| 0 | `sample` | 30000（神迹被毁） | 0（胜） | 44 | n/a（基线无旧版） | - |
| 1 | `sample_v2`（BlackBat 优先） | 0 | 1（负） | 99 | **1.9474** | 1.00（172 决策点全可比，无缺失） |

- **一次有效策略更新**：v1→v2 召唤优先级反转（`Archer>Swordsman>BlackBat`
  → `BlackBat>Archer>Swordsman`），决策分布真实改变。
- **IG 如实为正**：KL(v2‖v1) = 1.9474（ε-soft 口径，172 个同 obs 决策点均值）。
- **失败如实保留**：v2 反而输（score 30000→0）——曲线如实显示"更新后变差"，
  不粉饰；这正是迭代数据应有的样子。

曲线数据：`agentbench_data/runs/24_miracle/sample/*/summary.json`
（`build_curves` 汇总 → `curves_ascii` 输出 ASCII 表；可接入
AgentBenchResults 的 `compare.toml` 可视化）。

## 3. 边界与后续

- 本轮为**单 seed 单局受控演示**，非完整多轮迭代（用户明确不实跑完整闭环）；
  多轮由 `iterate.py` 驱动（`run_iteration` + `export_run` 即可扩展 iteration 2+）。
- 决策点 obs 从 trace 的完整 obs 帧提取（官方 from_logic 帧的 `state` 字段是
  round 号，非消息码；`content[0]` 前 6 位为长度前缀——见
  [[miracle-replay-reader]] skill 与 `docs/miracle/decision_space.md`）。
