# 26_snakego 游戏规则说明（贪吃蛇围棋）

## 棋盘与玩家

- 16×16 方格棋盘
- 2 名玩家（P0、P1），P0 起始位置右上角 (0,15)，P1 左下角 (15,0)
- 最多 512 回合

## 坐标系统

```
x ∈ [0, 16),  y ∈ [0, 16)
方向:  0=+x  1=+y  2=-x  3=-y
```

## 蛇

- 每方初始 1 条蛇，长度 1
- 蛇头在 `coor_list[0]`，蛇尾在 `coor_list[-1]`
- 前 8 回合每回合自动生长 +1
- 每方最多 4 条蛇（通过分裂）

## 动作码

| 码 | 动作 | 说明 |
|----|------|------|
| 1 | 移动 +x | 蛇头向 x+1 移动 |
| 2 | 移动 +y | 蛇头向 y+1 移动 |
| 3 | 移动 -x | 蛇头向 x-1 移动 |
| 4 | 移动 -y | 蛇头向 y-1 移动 |
| 5 | 轨道炮 | 沿蛇头方向发射，清除路径上所有墙壁 |
| 6 | 分裂 | 蛇从中间分成两条 |

## 回合结构

每个逻辑回合，双方各操作自己所有存活的蛇各一次。双方都操作完后：
- 回合数 +1
- 处理道具（过期/出现/拾取）

## 道具

| 类型 | 效果 | 说明 |
|------|------|------|
| type 0 | 加长 | `param` = 增加的长度（1-5），存入 `length_bank` |
| type 2 | 轨道炮 | 拾取后可使用轨道炮，持续 `param` 回合 |

道具出现后 16 回合过期。蛇头经过道具格时自动拾取。

## 围困机制（核心）

当蛇移动后头部碰到自己的身体时，触发 **solidify（固化）**：
1. 取从蛇头到碰撞点的蛇身段作为边界
2. 对边界做 flood-fill 检测，判断哪些区域被完全包围
3. 被包围的区域变为己方墙壁
4. 被围困的其他蛇（包括自己的）被消除

这是游戏的核心策略：通过控制蛇的移动路径来围困区域，获得领地。

## 轨道炮

- 需持有轨道炮道具
- 沿蛇头朝向发射
- 清除路径上所有墙壁（无论敌我）
- 使用后消耗道具

## 分裂

- 蛇从中间分成两条
- 头部保留轨道炮道具，尾部保留加长道具
- 增加地图覆盖，但单条蛇变短

## 计分

游戏结束（512 回合或某条件触发）时统计：

| 格子类型 | 得分 |
|----------|------|
| 己方蛇身格 | +2 / 格 |
| 己方墙壁格 | +2 / 格 |
| 首拾道具奖励 | +1（全场第一个拾道具的玩家） |

非法操作（如撞墙、回头）直接判负：该玩家得 -100 分。

## 胜负判定

- 分数高者胜
- 非法操作者判负

## 策略要点

1. **围困优先**：solidify 是得分大头，控制大区域比单条蛇长度更重要
2. **道具节奏**：加长道具增加体积，轨道炮可以破除对手围困
3. **分裂时机**：分裂增加覆盖但减少单条蛇的围困能力
4. **存活第一**：非法操作直接 -100 分，避免自杀性移动
